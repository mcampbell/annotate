# Modules

* [Image input](image-input.md) - Paste, Open button, and drag-drop all feed Annot.loadImage.
* [Style panel](style-panel.md) - Color and size inputs that style new objects and the selection.
* [Clipboard export](clipboard-export.md) - Copy writes the annotated image as a native-size PNG to the clipboard.
* [Undo and redo](undo-redo.md) - Object-only JSON snapshots, coalesced per task, restored with enlivenObjects.
* [Single-file build](build.md) - build.js inlines every local script and stylesheet into dist/annotate.html.
